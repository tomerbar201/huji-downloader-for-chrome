# HUJI Moodle Downloader

A Chrome Extension for bulk downloading course materials from the HUJI Moodle platform.

## Features
- Scans course pages for downloadable resources.
- Supports folders, resources, and assignments.
- Caching for fast path loading (SWR pattern).
- Background ghost scanning for updates.
- Sanitizes file names for cross-platform compatibility.

## Project Structure
- `moodle-downloader-mv3/`: The main extension source code.

## Installation
1. Clone this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable "Developer mode".
4. Click "Load unpacked" and select the `moodle-downloader-mv3` folder.
